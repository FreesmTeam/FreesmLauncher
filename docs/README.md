# 🚀 Introduction

*Freesm Launcher* is a **custom Minecraft launcher** that lets you manage multiple game installations and play **offline without needing a Mojang/Microsoft account**.  
It offers features like custom UI themes, animated “cat-pack” backgrounds, and Ely.by support (free authentication).  
Freesm is a **completely separate fork of the Prism Launcher** – it is **independent and not endorsed by the original Prism team**.  
All of its code is open source under GPL-3.0 (you can verify it yourself).

> [!NOTE]  
> Freesm Launcher is an independent fork of Prism Launcher and is **NOT affiliated** with the official Prism team.

---

## ✨ Features

- 🎮 **Offline Mode:** Play Minecraft without logging into an official account. No online authentication is required for offline worlds.
- 🔑 **Ely.by Support:** Built-in support for the free [Ely.by](https://ely.by/) authentication service as an alternative to online auth.
- 🎨 **Custom Themes & Icons:** Fully customizable interface with themes, color schemes, and icon packs (light/dark modes, accent colors, etc.).
- 🐱 **Animated Cat-Packs:** Support for animated (GIF) “cat pack” backgrounds and custom icons in the launcher UI.
- ✂️ **Image Cropping:** You can crop background images (cat-pack backgrounds) to better fit the launcher’s window.
- 🔄 **Multi-Instance Management:** Easily create and manage multiple Minecraft installations and modpack instances simultaneously.
- ☕ **Java Compatibility:** Java version checks are disabled by default for flexibility (you can enable compatibility mode if needed).
- 🛡️ **Open Source:** Freesm is free software under the GPL-3.0 license (no DRM, no hidden code). Anyone can audit, modify, or contribute to the code.

## 📥 Installation

### 🏷️ Stable Releases

Download Freesm Launcher from our [official website](https://freesmlauncher.org) or the [GitHub Releases](https://github.com/FreesmTeam/FreesmLauncher/releases) page. Packages available for **Windows, macOS, and Linux (x86-64)**.

### 🌙 Development Builds

For the latest features, check out the [GitHub Actions](https://github.com/FreesmTeam/FreesmLauncher/actions) artifacts or [Nightly Builds](https://nightly.link/FreesmTeam/FreesmLauncher/workflows/develop) (not recommended for most users).

> [!CAUTION]  
> Development (nightly) builds may be unstable, larger, and contain debug info. Use **at your own risk**.
